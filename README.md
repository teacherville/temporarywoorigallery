# 우리반 전시회 · 클라우드플레어 버전

기존 사이트(GitHub + 파이어베이스)와는 **완전히 따로** 돌아가는 새 사이트예요. 화면과 저장 서버가 모두 클라우드플레어 한 곳에 있어요.
무료 요금제만 쓰고 카드 등록은 필요 없어요. GitHub는 쓰지 않아요.

## 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `public/index.html` | 우리반 전시회 화면 (기존과 디자인·기능 같음) |
| `public/check.html` | 서버 점검 페이지 (누구나 열 수 있어요, 시험 전시회를 만들었다 바로 지워요) |
| `public/admin.html` | 운영자 페이지 (운영자 키가 있어야 열려요) |
| `src/index.js` | 저장 서버 |
| `wrangler.toml`, `package.json` | 클라우드플레어 설정 |

`public` 폴더에 넣으면 좋은 파일 (없어도 작동해요):
- 기존 저장소의 `favicon.png`, `thumbnail.jpg` → 탭 아이콘과 링크 미리보기 그림
- `three.min.js` (three.js **r128**) → 없어도 서버가 대신 받아서 우리 주소로 내보내요. 넣어 두면 바깥 사이트에 전혀 기대지 않아요 ([여기서 받기](https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js) → 다른 이름으로 저장)

## 처음 올리기 (한 번만)

1. **Node.js 설치**: [nodejs.org](https://nodejs.org)에서 **LTS** 버튼으로 받아 설치해요. 설치 화면은 계속 **Next**만 누르면 돼요.
2. **명령 창 열기**: 압축 푼 `woorigallery` 폴더를 열고, 탐색기 **주소창**에 `cmd`라고 쓰고 엔터. (맥: 터미널을 열고 `cd `를 친 뒤 폴더를 끌어다 놓고 엔터)
3. **로그인**: `npx wrangler login` → 브라우저에서 **Allow**. `Ok to proceed? (y)`가 나오면 `y` 엔터.
4. **올리기**: `npx wrangler deploy` → 처음이면 workers.dev 주소에 쓸 이름을 물어봐요(영어 소문자).
5. **운영자 키 정하기**: `npx wrangler secret put ADMIN_KEY` → 16자 이상 아무도 모를 긴 문장을 입력해요 (예: 영어+숫자 섞어 20자). 화면에 안 보여도 입력되고 있는 거예요. **잊어버리지 않게 따로 적어 두세요.**
6. `주소/check.html` → **서버 점검하기** → 11개 모두 ✓
7. `주소/admin.html` → 운영자 키로 들어가지는지 확인

## 고친 뒤 다시 올리기

명령 창에서 `npx wrangler deploy`만 다시 하면 돼요. **저장된 전시회는 그대로 남아요.**

## ⚠️ 절대 하지 말 것 (전시회가 모두 사라질 수 있어요)

- 클라우드플레어 대시보드에서 **woorigallery Worker를 지우기**
- `wrangler.toml`의 `class_name`(Show, Teacher, Registry, Gate)이나 `[[migrations]]` 부분을 **바꾸거나 지우기**
- `wrangler.toml`의 `name = "woorigallery"`를 바꾸기 (이름을 바꾸면 **새 빈 사이트**가 따로 생겨요)

## 무료 한도 (하루 단위는 한국 시간 오전 9시에 다시 채워져요)

| 항목 | 무료 한도 | 이 앱에서 쓰는 곳 |
|---|---|---|
| 화면 파일 | 무제한 | index.html, check.html, admin.html, 그림 |
| Workers 요청 | 하루 100,000번 | 입장(작품 받기), 저장, 실시간 연결 시작 |
| Durable Objects 요청 | 하루 100,000번 | 위와 같음 + 아이들이 보내는 움직임·쪽지 (20개 = 1번) |
| SQLite 쓰기 | 하루 100,000행 | 작품 저장, 쪽지, 따봉(2초마다 모아서 저장) |
| **저장 공간** | **전체 5GB** | 작품 사진 (30점 전시회 하나 ≈ 3MB → **약 1,500개**) |

- 대략 **30명 반 40분 수업 1번 ≈ 요청 2,000번** → 하루 40~50개 반까지.
- 한도를 넘으면 **돈이 나가지 않고** 그날은 멈춰요(화면에 "오전 9시에 다시 채워져요" 안내가 떠요). 유료로 바꾸지 않는 한 요금이 생기지 않아요.
- 사용량: 대시보드 **Workers & Pages → woorigallery → Metrics**. 오류 기록: 같은 곳의 **Logs**.

## 서버에 걸어 둔 안전장치

| 장치 | 값 | 왜 |
|---|---|---|
| 전시회 하나 작품 수 | 60점 (화면에서는 30점까지) | 저장 공간을 혼자 다 쓰지 못하게 |
| 전시회 하나 용량 | 12MB | 〃 |
| 작품 하나 크기 | 400KB (사진은 화면에서 약 110KB로 줄여 보내요) | 〃 |
| 같은 인터넷 주소에서 하루 새 전시회 | 60개 | 누군가 전시회를 마구 만들지 못하게 (학교 하나 = 보통 주소 하나) |
| 관리 코드 연속 실패 | 1시간에 20번 → 잠시 잠금 | 관리 코드 맞히기 공격 막기 |
| 전시회 하나 동시 접속 | 120대 | 한 전시회가 서버를 독차지하지 못하게 |
| 한마디·쪽지 보관 | 전시회마다 600개·300개 (넘으면 오래된 것부터) | 〃 |
| 다른 사이트에서 이 서버 쓰기 | 막음 | 남의 사이트가 우리 무료 한도를 쓰지 못하게 |

값은 `src/index.js` 맨 위에서 바꿀 수 있어요.

## 운영자 페이지 (admin.html)로 할 수 있는 것

- 전체 전시회 수, 작품 수, **저장 공간 추정치**, 6개월 넘게 안 쓴 전시회, 만들다 만 빈 전시회 보기
- 전시회 **보기**(사진·한마디·쪽지), 작품 하나 빼기, 글 하나 지우기
- 전시회 **닫기/열기**, **지우기**
- **내려받기**: 전시회 하나를 파일(.json)로 보관 (작품·글·관리 코드 포함)

## 자동으로 돌아가는 것 (사람이 할 일 없음)

| 걱정 | 자동 처리 |
|---|---|
| 저장 공간(5GB)이 언젠가 꽉 참 | **1년 동안** 선생님도 아이들도 안 들어온 전시회는 저절로 지워져요(작품이 0점인 전시회도 똑같이 1년). 그래도 추정 4.2GB를 넘으면 **가장 오래 안 쓴 전시회부터** 정리해요 |
| 지운 전시회의 코드가 다른 반에 다시 쓰임 (예전 QR로 남의 전시회에 들어감) | 한 번 쓴 코드는 다시 쓰지 않아요 |
| 선생님 목록에 지워진 전시회가 남음 | 목록을 열 때 저절로 빠져요 |
| 지워진 전시회 코드로 들어옴 | "지워졌거나 오래 안 써서 정리됐어요" 안내 |
| 3D 도구를 주던 바깥 사이트가 막히거나 바뀜 | 서버가 대신 받아서 저장해 두고 우리 주소로 내보내요 |
| 하루 무료 사용량 초과 | 돈은 안 나가고, 그날만 멈췄다가 오전 9시에 저절로 다시 열려요 |
| 장난으로 전시회를 마구 만들기, 관리 코드 맞히기, 남의 사이트가 우리 서버 쓰기 | 막혀 있어요 (위 '안전장치' 표) |
| 서버 프로그램 업데이트 | 필요 없어요. 한 번 올리면 그대로 계속 돌아가요. Node.js도 다시 쓸 일이 없어요 |

기간은 `src/index.js` 맨 위 `IDLE_DAYS`, `EMPTY_DAYS`(둘 다 365일)에서 바꿀 수 있어요.

## 그래도 사람이 해야 하는 일 (드물게)

- **부적절한 작품·글 신고**: 이용 안내에 "운영자가 지울 수 있어요"라고 적혀 있어서, 인스타그램 등으로 신고가 오면 운영자 페이지에서 지워야 해요. 평소에는 선생님이 자기 전시회의 글을 직접 관리해요(⋯ → 글 관리).
- **클라우드플레어에서 온 메일 확인**: 무료 요금제 정책이 바뀌면 메일이 와요. 계정 이메일을 자주 보는 주소로 해 두세요.
- **계정 보안**: 클라우드플레어 계정에 2단계 인증을 켜고, 복구 코드를 보관하세요. 회사 공용 이메일 계정을 추천해요.
- **꼭 남겨야 할 전시회**: 자동 백업은 없어요. 운영자 페이지 → 내려받기.
- **운영자 키를 잊어버림**: Node.js가 있는 컴퓨터에서 `npx wrangler secret put ADMIN_KEY`로 새로 정하면 돼요.

## 이용 환경 (기기·브라우저·인터넷)

### 되는 곳 / 안 되는 곳

| 환경 | 결과 |
|---|---|
| 크롬·엣지·웨일·삼성 인터넷 (PC·안드로이드) | ✅ 됨 |
| 아이폰·아이패드 (사파리·크롬 모두 같은 엔진) | ✅ 됨 (실제 기기로 꼭 한 번 확인) |
| 카카오톡·네이버·밴드 앱 안 브라우저 | ✅ 됨 · 사진 저장/복사가 막힐 수 있음 → '다른 브라우저로 열기' |
| 시크릿 창 | ✅ 됨 · 선생님은 창을 닫으면 목록이 사라지니 **선생님 전용 링크·관리 코드 보관** |
| 인터넷 익스플로러 | ❌ 안 됨 → "크롬·엣지로 열어 주세요" 안내가 떠요 |
| 3D 그래픽이 꺼진 PC | ❌ 3D 안 됨 → "휴대폰·태블릿이나 다른 브라우저로 열어 보세요" 안내가 떠요 |

### 화면에서 알아서 처리하는 상황

| 상황 | 처리 |
|---|---|
| 학교 인터넷이 실시간 연결(WebSocket)을 막음 | 자동으로 예비 방식(20초마다 받기)으로 바꿔요. 쪽지·따봉은 되고, 친구가 걷는 모습만 안 보여요 |
| 와이파이가 잠깐 끊김 / 휴대폰 화면을 껐다 켬 | 돌아오면 바로 다시 연결해요 |
| 느린 인터넷 (3G 정도) | 30점 전시회 입장에 약 17초. 90초까지 기다려요 |
| 쿠키·저장소 차단 (사파리 '모든 쿠키 차단' 등) | 전시회는 그대로 돼요. 선생님은 선생님 전용 링크로 열어야 목록이 보여요 |
| 학교 공용 컴퓨터 | 선생님 화면 → 선생님 전용 링크 상자 아래 **'이 컴퓨터에서 내 목록 지우기'** |
| 바깥 사이트(3D 도구)가 막힌 학교 | `public/three.min.js`를 넣어 두면 우리 사이트에서 바로 받아요 |
| 아이폰 사파리가 7일 넘게 안 쓴 사이트의 저장 내용을 지움 | 선생님 목록이 비면 "선생님 전용 링크·관리 코드로 불러오기" 안내가 떠요 |

### 실제 기기로 꼭 확인할 것 (여기서는 크롬으로 흉내만 냈어요)

각 기기에서 `주소/check.html`을 열면 **이 기기 정보 + 서버 점검**이 한 번에 나와요. 화면을 찍어 두세요.

- [ ] **학교 인터넷**에서 열리는지 (일부 학교·교육청 차단 프로그램이 `*.workers.dev`를 막을 수 있어요)
- [ ] 아이폰 / 아이패드 사파리: 3D 전시장 걷기, 따봉, 한마디, 포토존 사진 저장
- [ ] 갤럭시 삼성 인터넷: 같은 항목 + **다크 모드**에서 화면 색이 이상하지 않은지
- [ ] 카카오톡으로 받은 링크를 눌러 들어가기 (앱 안 브라우저)
- [ ] QR을 휴대폰 기본 카메라로 찍어 들어가기
- [ ] **터치 화면 노트북**: 화면에 조이스틱이 나오는데 키보드 방향키로도 걸어지는지
- [ ] 오래된 태블릿·저가형 노트북: 3D가 너무 느리지 않은지
- [ ] 아이들 30명이 한꺼번에 들어갔을 때 (첫 수업 전에 몇 명이라도 같이 시험해 보기)
